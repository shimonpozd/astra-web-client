# Руководство по стилям CSS (STYLE_GUIDE)

Этот документ описывает правила организации и поддержки CSS-кода в проекте.

## Основные правила

1. **Один домен — один файл**
   - Новый визуальный модуль или компонент (например, FocusReader, Bookshelf) создаётся в виде отдельного файла в `src/styles/components/`, а не добавляется в `index.css` или соседние домены.
   - Каждый файл должен начинаться с комментария с кратким описанием назначения файла и использующих его компонентов.

2. **Цвета только через токены темы**
   - Не захардкоживайте hex или rgba цвета по месту в компонентных стилях.
   - Используйте существующие HSL-переменные из `src/styles/base/theme.css` (`hsl(var(--primary))`, `hsl(var(--foreground))`), либо создавайте новые токены в `theme.css`.

3. **Один селектор — одно определение**
   - Все состояния элемента (`:hover`, `:active`, `.is-active`) описываются в одном блоке файла домена.
   - Не дублируйте один и тот же селектор в разных частях файла или разрозненных слоях.

4. **Последовательное использование `@layer`**
   - Базовые стили оформляются внутри `@layer base` в `base/reset.css` или `base/theme.css`.
   - Компонентные стили помещаются в `src/styles/components/` и импортируются в `index.css` после директив Tailwind (`@tailwind components` / `@tailwind utilities`).
